Early execution

Mark it #static and the compiler runs the code now, baking the result into the binary. Any k1 code can run at compile time. That is the whole of k1's metaprogramming, and it is how build steps disappear: dbx pulls SQLite into the k1 fold this way, the dependency, the bindings and the schema, so tables become k1 types before the program runs.
