# gengame ideas

idea: sound — tiles as notes, reps = rhythm, shift = transposition (drift is a canon,
interference a phase pattern); space plays target melody then yours, hear the diff
before you see it; synth PCM into a raylib audio stream, render-layer only

idea: stochastic plants — a rule may carry variants and each expansion site picks
one by a visible per-level seed die ("weather"); fixed seed keeps expansion
deterministic so exact-match scoring still works, and rerolling the die shows the
same program growing a different individual — variation lives in the world, not
the program, which is the actual L-system lesson

Adding parameter-taking 'functions' to the seq world could be a great mechanic
- will teach parameterization and abstraction in a neat way

polished-game idea: always-on minimap of the max-growth target next to the growth scrub

Other game ideas:
Geometry; try to make a triangle where pythagorean doesnt hold; interactive visual
          bars / meters for each thing
Numbers:  Peano numbers first, build yourself up to integers written with digits
Algebra: each level proves or discovers an identity or rule, you can only use it
         once discovered
